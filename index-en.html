Installing on Android

  1. Download the APK, then open it from your browser's downloads.
  2. Because the APK is not from Google Play, Android will ask you to allow installs from the current browser or file manager. Enable that permission, return and continue.
  3. If Android reports an app conflict, signature mismatch or refuses to update, export a Shannian backup first, uninstall the old app, then install this APK.

Important: uninstalling removes local practice data. Before uninstalling, use More → Data & Preferences → Backup & Restore to export a backup.

The default package is about 31 MB. If it cannot be installed, try the universal package (about 80 MB).
