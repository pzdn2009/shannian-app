Shannian Support

Feedback, backup recovery and installation help

Thank you for using Shannian. For a problem or feature suggestion, email pzdn2009@gmail.com.

You can also open More → About Shannian → Feedback in the app and send the prepared template through WhatsApp or email.

Include your device model, OS version, app version and the steps that reproduce the problem. Do not send unnecessary sensitive information.

Saving and restoring data

Practice records and settings stay on your device by default. Before changing devices, reinstalling or switching installation channels, export a full backup from More → Data & Preferences → Backup & Restore and keep it somewhere safe. Use Restore from Document to import it later.

Installing on Android

The APK is distributed outside Google Play. When Android asks, allow the browser or file manager that downloaded the APK to install unknown apps. If Android reports an app conflict or signature mismatch, export a backup first, uninstall the old app, then install the new APK.

Uninstalling removes local data from that device. Always export a backup first.

Deleting data

You can delete individual records inside Shannian. Uninstalling Shannian removes all local data stored by the app on that device.
