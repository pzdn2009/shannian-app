Release Notes

Important Shannian features, experience improvements and bug fixes. Downloads and older packages remain available on GitHub Releases.

Shannian 1.1.6Released

11 November 2026

  • Added a Languages setting with Default, 中文 and English. Default follows the device language. This changes interface labels only; scriptures, chant names, titles, notes and downloaded content remain unchanged.
  • Added Migrate Cumulative Data under More → Data & Preferences. You can enter chant totals for all time, this year and this month, or migrate completed scripture rounds and the current round's progress. Shannian asks for confirmation before replacing existing totals.
  • Added undo for accidental actions: the chant counter can undo the latest +1 or +10, while the Recite menu can undo today's latest recitation without changing scripture text, bookmarks or memorization progress.
  • Added Android APK update checks. Shannian checks at most once per day without blocking startup when GitHub is unavailable; you can also check manually from About Shannian and open the latest APK download.

These experience improvements were suggested by LinFa. Thank you for the thoughtful feedback.
