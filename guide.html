善念使用教程

用一个清晰的日常节奏，安排念佛、经咒、禅观与回向。善念无需注册，修持数据默认保存在你的设备上。

一门深入 今日修持 念佛 经咒 禅观 回向与记录 附近服务 设置与数据 反馈问题

1一门深入，余行随缘

善念不希望把修持变成越来越长的打卡清单。更稳定的方式，是以少量主修作为每日锚点，兼修按周期缓缓推进，空余时随力行持。

主修

选 1–2 项真正想长期安住的功课，每日稳定继续，不被其他项目挤掉。

兼修

长经或阶段性功课不必每天强求同样的量，按本周期总量跟踪即可。

随力

精力、时间具足时再做，不计入完成率，也不因今日没做而增加压力。

也可以完全不设目标

修持计划是用来整理节奏的可选工具，不是使用 App 的前提。不设置任何目标时，仍可直接从底部进入“念佛”、“经咒”或“禅观”，正常计数、阅读、念诵和计时。什么时候需要更稳定的周期，再回到“功课”页设置计划。

核心原则：目标服务于修持，不让修持反过来服务于目标。

2今日修持

功课 → 右上角“修持计划”
  1. 设置周期天数和开始日期。
  2. 选择 1–2 项主修，并设定每日数量。
  3. 可选 1 项兼修和多项随力，预览后启动。

主修完成

达到当日目标后从执行列表收起；全部完成时只保留一条绿色摘要。

兼修节奏

按周期累计进度判定“今日已跟上”，不制造每日欠账。

随力候选

首页每次最多显示 3 项，可刷新更换；当日达标后不再出现。

自动估时

点击“开始”便按本次目标计时；有历史记录后，会优先使用你的个人均时。

计时达标会播放完成提示音。修改或结束计划不会删除已有修持记录、经文进度和个人均时。

3念佛

底部“念佛” → 选择佛号
  • 轻点主计数区 +1；完成一组十念后，切换“⑩”可一次记入 +10。
  • 连续播放会自动计数；每百遍和计划完成提示音可在设置中控制。
  • 佛号可新增、编辑或删除；内置“南无阿弥陀佛”不可删除，也不可重复添加。

十念记数

此功能借鉴印光大师在《复高邵麟居士书四》中开示的十念记数法：一句佛号为一念，从一至十循环，重在念清、记清、听清。若直记十句较难，可分成 5+5 或 3+3+4。这与以一口气为一念的“晨朝十念”不同。

“⑩ +10”只记录已完成的一组十念，不代替实际念诵。

出处：《增广印光法师文钞·复高邵麟居士书四》。查看原文

4经咒

底部“经咒” → 经典 → 章节

阅读

静态阅读分段正文，不记书签，不因滚动改变进度。

背诵

逐句标记“记住一句”，可播放本句、回看正文并记录段落要点。

念诵

按品、卷、会或章节顺序完成；只有明确点击完成才会更新进度。

拼音与发音

菜单可显示逐字拼音；念诵模式可校准单字发音，全局规则在设置中管理。

下载与编辑

  • 右上角进入“在线经藏”，可搜索 Deerpark / CBETA，并选择按品会章或按原卷数下载。
  • 下载后可离线使用；删除本地正文不会删除已有修持记录。
  • “编辑本地经文”按段修改。经文准确性重要，保存前请复核原文。

5禅观

底部“禅观” → 选择方法
  1. 阅读方法说明，选择 5、10、20、30 分钟或自定义时长。
  2. 开始后进入全屏计时，可暂停、继续或提前结束并保存实际用时。
  3. 六妙门按“数、随、止、观、还、净”次第开启；达到阶段目标后，仍由你主动开启下一门。
  4. 可新增自定义方法；删除方法不会删除历史记录。

建议允许通知，锁屏或 App 在后台时仍可在计时结束时提醒。

6回向与记录

回向

从功课首页进入。页面会汇总自上次回向后新增的念佛、经咒、禅观和持戒记录。

修持记录

从“更多 → 数据与偏好 → 修持记录”查看每日和累计数据。

持戒

首页的农历与十斋日卡片可进入当日持戒确认；持戒独立记录，不影响功课完成率。

数据原则

回向、改名、调整或结束计划都不会重写原始修持记录。

7附近服务与法讯

更多 → 附近素食 / 附近寺庙 / 法讯
  • 附近素食和寺庙支持关键字搜索、地图与列表、地点定位以及跳转系统地图导航。
  • 只有在你主动搜索时才使用定位；拒绝权限后仍可手动输入地区或关键字。
  • 法讯提供近期、月历与地图视图。参加前请再次核对寺院官方页面。

8设置与数据

更多 → 右上角设置
  • 外观：跟随系统、浅色或深色，以及简体/繁体。
  • 阅读与播放：背诵入口、经文字号、播放语速、每遍停顿和念诵估速。
  • 念佛：“播放频率”控制连续语音；“计数频率”只用于没有个人样本时的手动念佛估时，两者互不代替。
  • 提醒：可开启温和修持提醒并设置时间。

备份与恢复

更多 → 数据与偏好 → 备份与恢复
  1. 点击“导出备份”，把文件保存到云盘或其他安全位置。
  2. 在新设备上选择“从文档恢复”，检查预览后确认覆盖。
  3. 恢复完成后按提示完全重启 App。

卸载 App 会删除本机数据。换机、卸载或更换安装渠道前，请先导出备份。
